## 2 Прототип ML-сервиса для прогноза погодных условий

- ### Парадигмы:
    * Дифференцируемое программирование
    
- ### Язык программирования:
    * Python

- ### Обоснование:
    * Программирование на питоне позволяет быстро сделать mvp продукт из-за простого синтекса и большого количества материалов по языку
    * Используя условие что программа должна запускаться 1 раз в сутки нам не нужна скорость, поэтому задержки интерпретируемого языка как питон не сильно важны
    * Готовые библиотеки в виде PyTorch, TensorFlow для сборки нейронных сетей, что позволяет не писать математические алгоритмы и работы с матрицами с 0

## 3 Интерактивный UI для торгового терминала

- ### Парадигмы:
    * Функциональный
    * Реактивный

- ### Язык программирования:
    * TypeScript

- ### Обоснование:
    * Компилируется в чистый JavaScript и выполняется на сверхбыстрых современных движках вроде V8 (Chrome, Node.js), но при этом имеет статическую типизацию данных, что дает нам легкую тестируемость (предотвращает ошибки несоответствия структур данных)
    * Интерфейс меняется только на измененных данных, а не изменяя весь интерфейс сразу

## 4 Прошивка для устройства регистрации температуры
- ### Парадигмы:
    * Императивная
- ### Язык программирования:
    * C
- ### Обоснование:
    * Ограниченные ресурсы микроконтроллера, из-за того что язык C низкого уровня программы не занимают много места, и компилируется напрямую в машинный код, что еще и благодаря этому тратится минимальное количество заряда батарии
    * нет больших библиотек, занимающих много места на плате
    * В микроконтроллерах каждый порт (GPIO, UART, ADC) — это просто конкретный адрес в оперативной памяти (Memory-Mapped I/O). Язык C позволяет превратить любой физический адрес памяти в переменную с помощью указателей.
    * Стандартизированность языка и наличие компиляторов C под любую архитектуру
