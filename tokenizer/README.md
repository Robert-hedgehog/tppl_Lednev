# Лексический анализатор (токенизатор)

Программа выполняет лексический анализ исходного кода из файла, разбивает его на последовательность токенов с указанием их типа и позиции (`строка:столбец`) и сообщает о лексических ошибках.

## Структура проекта

```text
tokenizer/
├── tests/
│   ├── __init__.py
│   └── test_main.py
├── input.txt
├── main.py
└── README.md
```

## Распознаваемые токены и синтаксис

Пробелы, символы табуляции, переводы строк и комментарии (от `#` до конца строки) пропускаются.

* `IDENT` — идентификаторы (последовательность букв, цифр и `_`, не начинающаяся с цифры).
* `KEYWORD` — ключевые слова: `if`, `else`, `while`, `return`, `for`, `def`.
* `INT` — целые числовые литералы.
* `FLOAT` — вещественные числовые литералы.
* `STRING` — строковые литералы в двойных кавычках (`"..."`).
* `OP` — операторы: `+`, `-`, `*`, `/`, `=`, `<`, `>`, `==`, `<=`, `>=`.
* `SEP` — разделители: `(`, `)`, `{`, `}`, `,`, `;`.

## Запуск

Перейдите в директорию `tokenizer`:

```bash
cd tokenizer
```

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
```

Активируйте виртуальное окружение:

* Linux / macOS / WSL:
  ```bash
  source .venv/bin/activate
  ```

* Windows (PowerShell):
  ```powershell
  .venv\Scripts\Activate.ps1
  ```

Для запуска самого анализатора сторонние библиотеки не требуются. Для запуска тестов установите `pytest` и `pytest-cov`:

```bash
pip install pytest pytest-cov
```

### Запуск программы

Передайте путь к любому `.txt` файлу с исходным кодом через аргумент командной строки (например, `input.txt`):

```bash
python main.py <путь_к_файлу>.txt
```

Пример содержимого `<путь_к_файлу>.txt`:

```text
x = y * 2 + z * 3
```

Пример вывода в терминал:

```text
(IDENT, x, 1:1)
(OP, =, 1:3)
(IDENT, y, 1:5)
(OP, *, 1:7)
(INT, 2, 1:9)
(OP, +, 1:11)
(IDENT, z, 1:13)
(OP, *, 1:15)
(INT, 3, 1:17)
```

При обнаружении недопустимого символа (например, `a @ b`) программа завершается с ненулевым кодом возврата и выводит ошибку в формате:

```text
input.txt:1:3: lexical: unexpected character '@'
```

## Тестирование

Запуск тестов с помощью `pytest`:

```bash
pytest
```

Запуск тестов с проверкой покрытия кода и выводом строк, не покрытых тестами:

```bash
pytest --cov=main --cov-report=term-missing
```
