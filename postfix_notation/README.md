# Стековая машина (постфиксная нотация)

Программа реализует интерпретатор арифметических выражений, записанных в обратной польской нотации (постфиксной форме), с пошаговой визуализацией состояния стека.

## Структура проекта

```text
postfix_notation/
├── tests/
│   ├── __init__.py
│   └── test_main.py
├── main.py
├── requirements.txt
└── README.md
```

## Операции и синтаксис

Элементы выражения передаются через пробел.

* **Целые числа** — помещаются в стек.
* `+` — сложение двух верхних операндов (`a + b`).
* `-` — вычитание (`a - b`).
* `*` — умножение (`a * b`).
* `/` — целочисленное или вещественное деление (`a / b`) с валидацией деления на 0.
* `~` — специальный оператор:
  * Если оба операнда не равны нулю (`a != 0` и `b != 0`): извлекает их, считает модуль разности `|a - b|` и кладет обратно в стек.
  * Если хотя бы один операнд равен нулю (`a == 0` или `b == 0`): суммирует все оставшиеся элементы стека вместе с `a` и `b`, возводит полученную сумму в квадрат `(sum + a + b)^2`, очищает стек и записывает в него только результат.


## Запуск

Перейдите в директорию `postfix_notation`:

```bash
cd postfix_notation
```

Создайте виртуальное окружение:

```bash
python3 -m venv .venv
```

Активируйте виртуальное окружение:

* Linux / macOS / WSL:
  ```bash
  source .venv/bin/activate
  ```

* Windows (PowerShell):
  ```powershell
  .venv\Scripts\Activate.ps1
  ```

Установите необходимые зависимости:

```bash
pip install -r requirements.txt
```

### Запуск программы

Передайте выражение в виде аргумента командной строки:

```bash
python main.py "3 0 4 ~ 2 ~"
```

Пример вывода в терминал:

```text
Вычисляем: `3 0 4 ~ 2 ~`
Шаг 1: число 3 -> стек: [3]
Шаг 2: число 0 -> стек: [3, 0]
Шаг 3: число 4 -> стек: [3, 0, 4]
Шаг 4: '~' -> стек: [49]
Шаг 5: число 2 -> стек: [49, 2]
Шаг 6: '~' -> стек: [47]

`3 0 4 ~ 2 ~ = 47`
```

## Тестирование

Запуск тестов с помощью `pytest`:

```bash
pytest
```

Запуск тестов с проверкой покрытия кода и выводом строк, не покрытых тестами:

```bash
pytest --cov=main --cov-report=term-missing
```
